# EchoVoice für macOS

[**Aktuelle Version herunterladen**](https://github.com/ISOH-Sabolowitsch/EchoVoice-Downloads/releases/latest)

Öffne das neueste Release, lade die Datei mit der Endung `.dmg` und ziehe **EchoVoice.app** in den Programme-Ordner. EchoVoice läuft auf Macs mit Apple Silicon ab macOS 14.

Ab Version 0.2.11 zeigt EchoVoice die installierte Version unten rechts im Hauptfenster. Unter **Einstellungen → Updates** kannst du nach einer neuen Version suchen und die Prüfung beim Programmstart ein- oder ausschalten. Der Download beginnt nach deiner Bestätigung.

Dieses Repository stellt die DMGs und die signierte [Update-Liste](https://github.com/ISOH-Sabolowitsch/EchoVoice-Downloads/releases/latest/download/appcast.xml) ohne Anmeldung bereit.
